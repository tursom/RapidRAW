Windows 勾选后安装原生接收器，单独记录 AdditionalObjects 返回的路径或错误；发送成功不代表路径可用。

对照模式会依次执行两条路径，总耗时不代表原始 PNG 优先的耗时；请分别运行各模式比较。原始 PNG 仍会完整解码校验并计算哈希，不会重新编码。
